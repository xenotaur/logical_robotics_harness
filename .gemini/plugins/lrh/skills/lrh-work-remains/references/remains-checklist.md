# Work-Remains Checklist

This is the fixed, 18-item checklist `/lrh-work-remains` reports against.
Copied verbatim from the source prompt — do not paraphrase, reorder, merge,
or drop items. Report each one explicitly, including an explicit "nothing
outstanding" statement when a category has no findings — a silently omitted
category is indistinguishable from one that was checked and found clean.

1. Incomplete work
2. Unanswered questions
3. Uncommitted files
4. Feature branches not pushed to main
5. Open PRs not yet merged
6. Unaddressed comments on PRs
7. Incomplete closeouts of PRs
8. Stray files
9. Stale branches
10. Unsaved memories
11. Untaken offers
12. Unaddressed issues
13. Control plane updates
14. Open work items
15. Unfinished workstreams
16. Documentation updates
17. Dogfooding of user-facing features
18. Other unfinished scope of work
