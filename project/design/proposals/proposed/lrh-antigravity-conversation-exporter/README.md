# LRH Antigravity Conversation Exporter proposal set

This proposal set records the proposed Google Antigravity conversation session export path for LRH: private-by-default transcript artifacts with generalized structured manifests, deterministic inspection commands, and native agent skill adaptation.

## Status

`proposed` / `not_started`

This is a documentation-only design proposal. It does not implement an Antigravity adapter, transcript archive, manifest schema generalization, inspection command update, viewer route, storage backend, redaction pipeline, or promotion workflow.
