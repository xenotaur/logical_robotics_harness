# LRH Console visual language mockup assets

- `alternative_d_enhanced_swimlane_console_light.png` and
  `alternative_d_enhanced_swimlane_console_dark.png`: the Alternative D images, now the visual
  reference for the statusboard (see the proposal's Revision 2 vocabulary).
- `lrh-console-frame-mock.html`: the Revision 2 interactive mock. It shows the app frame (top bar,
  scoped sidebar, icon rail, detail drawer), the banded statusboard, and a lane-by-phase
  dependency map. It has Light, Dark, and System themes and a colorblind-safe palette. Open it in
  a browser; it needs only Google Fonts for Montserrat and falls back to system fonts offline.

These assets are illustrative references for visual direction, information hierarchy, mood, and
semantic grouping, using sample data. They are not pixel-perfect implementation requirements and
should not determine a frontend framework, exact component geometry, or final token values. The
mock's `:root` block is the draft for the shared token file.
